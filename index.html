هیچ تۆمارێک بۆ ئەم ڕۆژە نییە
• «ناردن بۆ WhatsApp» تەنها یەک فایلی JSON دەنێرێت. لە لیستی هاوبەشکردن WhatsApp هەڵبژێرە و چات یان گرووپ دیاری بکە.
• تۆمارە هەڵبژێردراوەکان لە یەک فایلی JSON دەنێردرێن؛ ئەگەر هیچ هەڵنەبژێریت، هەموو تۆمارە پیشاندراوەکان دەنێردرێن. لە براوزەری نەپشتگیریکراودا فایل دابەزێنرێت.
• داتاکان لەسەر ئەم ئامێرە لە براوزەر پاشەکەوت دەکرێن. بۆ پاراستن بەردەوام Export JSON بکە.
